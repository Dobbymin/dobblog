## 핵심 관점

좋은 skill은 모델에게 긴 설명을 다시 읽히는 문서가 아니다. 특정 일을 안정적으로 수행하게 만드는 작은 작업 환경이다.

## Skill이 해결하는 문제

LLM은 매번 같은 맥락을 처음부터 추론한다. 프로젝트별 규칙을 잊고, 도구 순서를 다시 설명해야 하며, 실수 비용이 큰 파일 포맷이나 배포 절차에서 임의로 판단하기 쉽다. skill은 이런 지식을 폴더 단위 패키지로 만든다.

## 기본 구조

```text
my-skill/
├── SKILL.md
├── agents/openai.yaml
├── scripts/
├── references/
└── assets/
```

`SKILL.md`는 진입점이다. 트리거 조건, 핵심 절차, 안전 규칙을 작게 유지한다. 스크립트는 반복 작업을 고정하고, reference는 필요할 때만 읽게 구성한다.

## 설계 원칙

1. 한 skill은 한 가지 문제를 잘 해결한다.
2. 설명보다 실행 가능한 스크립트와 템플릿을 우선한다.
3. 검증 방법과 실패 시 대처를 포함한다.
4. 의존성과 권한 요구를 명확히 적는다.

작은 작업 환경으로 시작하고, 실제 사용에서 반복되는 실수만 추가하는 편이 오래 유지된다.
