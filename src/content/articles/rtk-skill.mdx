## 한 줄 요약

RTK는 `ls`, `grep`, `git`, `cargo test` 같은 개발 명령어 출력을 LLM 컨텍스트에 들어가기 전 압축하는 Rust CLI 프록시다. `caveman`이 모델의 출력을 줄인다면, RTK는 모델이 읽는 명령어 결과를 줄인다.

## 압축 전략

- 스마트 필터링: 주석, 공백, 보일러플레이트 제거
- 그룹핑: 비슷한 파일과 오류를 묶음
- 트렁케이션: 핵심 맥락만 남김
- 중복 제거: 반복 로그를 횟수와 함께 한 줄로 접음

## Claude Code 연동

핵심 연동 방식은 `PreToolUse` 훅이다. 에이전트가 Bash 명령을 실행하려 할 때, 훅이 `git status`를 `rtk git status`처럼 바꿔 실행한다. 사람이 명령 습관을 매번 바꾸지 않아도 된다.

## 역할 분리

출력 토큰 절약은 응답을 간결하게 만드는 `caveman`이 맡고, 입력 토큰 절약은 도구 출력을 정리하는 RTK가 맡는다. 둘은 같은 문제의 다른 지점을 다룬다.
