## 한 줄 요약

`caveman`은 Claude Code 같은 코딩 에이전트의 답변을 압축해 출력 토큰을 줄이는 스킬이다. 군더더기만 걷어내고 기술적 내용은 그대로 둔다.

## 무엇을 줄이는가

LLM 답변에는 인사말, 의미 없는 부사, 필요 이상의 완결 문장이 자주 섞인다. 이 스킬은 관사와 필러 표현을 빼고, 필요할 때는 토막말을 사용한다. 핵심은 **줄이는 것은 말투이고 내용은 아니다**라는 점이다.

코드 블록, 함수 이름, API 이름, CLI 명령어, 오류 메시지는 바꾸지 않는다. 사용자 언어도 그대로 유지한다.

## 동작 방식

모델을 바꾸거나 별도 후처리를 하지 않는다. `SKILL.md`가 에이전트에게 압축 규칙을 제공하는 방식이다.

1. 설치 시 스킬 파일을 에이전트 설정 폴더에 둔다.
2. 요청이 스킬 설명과 맞으면 규칙을 읽는다.
3. 응답에서 필러를 빼고 핵심 사실과 다음 행동만 남긴다.

## 사용할 때 주의할 점

보안 경고, 되돌릴 수 없는 작업 확인, 순서가 중요한 여러 단계는 지나친 압축이 위험할 수 있다. 이때는 명확성이 토큰 절약보다 우선이다.
